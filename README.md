# 📦 Inventory Management System

A simple and interactive C# Console Application designed to manage store inventory effectively. It allows users to add new products, update stock quantities, view product lists, and remove items.

---

## 🚀 Features

* **Add Product:** Add new items with their name, price, and initial quantity.
* **Update Stock:** Easily increase or decrease product quantities with safety checks for insufficient stock.
* **View Inventory:** Display a complete list of all stored products, including their prices and available stock.
* **Remove Product:** Delete specific products from the system.
* **Interactive Menu:** A user-friendly console menu loop for seamless navigation.

---

## 🛠️ Technologies & Concepts

* **Language:** C#
* **Concepts:** Object-Oriented Programming (OOP), Collections (`List<T>`), Conditional Logic, Control Flow & Loops.
